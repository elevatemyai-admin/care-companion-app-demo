# Care Companion (Demo)

A demo version of Care Companion that uses made-up sample data.

- No database, no login, no API keys, no environment variables.
- Everything shown (names, symptoms, medications, vent entries, chat) is fictional.
- Nothing you type is saved. Refresh the page and it resets.
- The Ask chat uses pre-written answers, so it never uses AI credits.
- Sample dates are generated from today's date, so the demo always looks current.

## Deploy

1. Create a new GitHub repository and add these files.
2. In Vercel: Add New, Project, import the repo, click Deploy. No settings needed.
